# قالب اطلاعات پروژه‌ها

برای هر پروژه همین اطلاعات را بفرستید. متن‌های طولانی می‌توانند خام باشند؛ هنگام ورود داده برای نمایش در سایت ویرایش می‌شوند.

```text
عنوان فارسی:
عنوان انگلیسی:
دسته: شرکتی | مستقل
نام شرکت یا کارفرما:
نقش من:
بازه‌ی زمانی:
توضیح کوتاه (یک یا دو جمله):

معرفی کامل پروژه:
مسئله یا چالش اصلی:
راه‌حل و کارهایی که انجام دادم:
نتیجه و دستاوردها (ترجیحاً همراه عدد):

تکنولوژی‌ها:
خدمات یا مسئولیت‌ها:
آدرس نسخه‌ی آنلاین:
آدرس مخزن کد (در صورت عمومی بودن):

مسیر فایل تصویر کاور:
مسیر اسکرین‌شات‌ها + توضیح کوتاه هر تصویر:
```

پیشنهاد تصویر: یک کاور افقی با نسبت حدود `16:10` و سه تا شش اسکرین‌شات باکیفیت از بخش‌های مهم محصول.
